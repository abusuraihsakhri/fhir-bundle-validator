    Checks cover Bundle type, resource identifiers, R4 Bundle invariants bdl-1 through bdl-5 and bdl-7 through bdl-12, plus local reference warnings. Passing is not evidence of complete FHIR conformance: resource schemas, required clinical resource fields, implementation-guide profiles, terminology bindings, and external references are not fully validated.

    Input stays in browser memory. Avoid patient data on shared devices. Downloaded reports contain issue paths and messages, not source JSON.
